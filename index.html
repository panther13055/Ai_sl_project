AGENT ARCHITECTURE

Sense → Evaluate → Decide → Act → Repeat

01SENSE

Read occupancy, room temperature, daylight, target, tariff and budget.

02EVALUATE

Generate valid light, fan and AC combinations for the current rooms.

03DECIDE

Score comfort, power use and switching, then reject unaffordable plans.

04ACT

Select the highest-utility affordable appliance plan.

05REPEAT

Advance five minutes, update temperature, energy, cost and history.

What makes it AI?

HomePulse is a utility-based intelligent agent: it observes an environment, evaluates alternatives with a utility function and selects actions that best satisfy its goals and constraints. It is not a trained machine-learning model.
